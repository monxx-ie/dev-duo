# Dev Duo

A mini portfolio page made by two students to practice Git and GitHub.

## Purpose
Show a clean Git workflow: commits, feature branches, and a merge into `main`.

## Features
- Intro card for each partner
- Simple responsive layout (HTML + CSS only)

## How to view
1. Clone the repository
2. Open `index.html` in a browser

## Team
- Cassandra: profile card A, README
- Carl: profile card B, styling

## What we learned
We learned how to work on separate feature branches, make meaningful commits, and merge our work into main without breaking each other's changes.
